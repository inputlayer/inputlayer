# Quick Start

Get InputLayer running and execute your first query.

## 1. Install

```bash
# Clone the repository
git clone https://github.com/inputlayer/inputlayer.git
cd inputlayer

# Build (requires Rust 1.88+)
cargo build --release
```

## 2. Start the Server and Client

```bash
# Start the server
./target/release/inputlayer-server
```

On first boot the server creates an `admin` user and an admin API key, and saves both to `./data/credentials.toml`:

```toml
admin_password = "..."
api_key = "..."
```

The client authenticates with the API key, from `--api-key` or the `INPUTLAYER_API_KEY` environment variable. In another terminal:

```bash
export INPUTLAYER_API_KEY=$(sed -n 's/^api_key = "\(.*\)"/\1/p' data/credentials.toml)
./target/release/inputlayer-client
```

You should see:
```
Connecting to server at http://127.0.0.1:8080...
Connected!

Server status: healthy
Authenticated as: admin
Current knowledge graph: default
```

Running the [Docker image](installation#option-3-docker) instead? Read the same file with `docker exec inputlayer cat /var/lib/inputlayer/data/credentials.toml`.

## 3. Add Some Data

```iql
+person[("alice", 30), ("bob", 25), ("charlie", 35)]
```

Output:
```
Inserted 3 fact(s) into 'person'.
```

## 4. Query the Data

```iql
?person(Name, Age)
```

Output:

| Name | Age |
|---|---|
| "alice" | 30 |
| "bob" | 25 |
| "charlie" | 35 |

*3 rows*

## 5. Add a Filter

```iql
?person(Name, Age), Age > 28
```

Output:

| Name | Age |
|---|---|
| "alice" | 30 |
| "charlie" | 35 |

*2 rows*

## 6. Create a Rule

```iql
+senior(Name) <- person(Name, Age), Age >= 30
```

Output:
```
Rule 'senior' registered.
```

```iql
?senior(X)
```

Output:

| X |
|---|
| "alice" |
| "charlie" |

*2 rows*

## 7. Watch the Conclusion Change

`senior` is not a stored list: it is derived from `person` and stays current as the facts change. Bob turns 30, and Charlie leaves:

```iql
-person("bob", 25)
+person("bob", 30)
-person("charlie", 35)
```

Output:
```
Deleted 1 facts from 'person'.
Inserted 1 fact(s) into 'person'.
Deleted 1 facts from 'person'.
```

```iql
?senior(X)
```

Output:

| X |
|---|
| "alice" |
| "bob" |

*2 rows*

Bob is now derived as a senior and Charlie's conclusion is retracted, with no rule re-run by hand. An agent does not even poll for this: a [standing query](websocket-api) pushes each change as it happens.

## 8. Use Aggregation

```iql
+average_age(avg<Age>) <- person(_, Age)
```

Output:
```
Rule 'average_age' registered.
```

```iql
?average_age(X)
```

Output:

| X |
|---|
| 30.0 |

*1 rows*
