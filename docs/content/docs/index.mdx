# Documentation

Welcome to the InputLayer documentation. InputLayer is the live rules engine for AI agents: you declare facts and rules once, the engine keeps every conclusion current as facts change and pushes the exact changes to subscribed agents, and an agent's action is recorded only while the rules allow it. The facts and rule-derived conclusions of one domain form a knowledge graph, which is what the engine holds.

New here? Start with [What InputLayer Replaces](/docs/guides/what-it-replaces) and [Where It Sits](/docs/guides/where-it-sits), then the [Quick Start](/docs/guides/quickstart).
