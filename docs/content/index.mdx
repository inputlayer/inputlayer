# InputLayer

*The live rules engine for AI agents.* Take the rules out of your prompts.

**Your agents act on what's true now.** You write facts as they change and declare the reasoning as rules - compatibility, ownership, access policies - and the engine derives what follows. Facts and rules live outside the prompt, so your agent is not limited by the context window: when a fact changes, only the affected conclusions are recomputed, a conclusion that stops being true is withdrawn, and every result traces back to the rules and facts that produced it. A knowledge graph is what the engine holds: the facts and rule-derived conclusions of one domain.

For what InputLayer replaces in an agent stack, what it keeps and where it sits, see the [project README](https://github.com/inputlayer/inputlayer#readme).

These docs cover the mechanism: facts, rules, queries, and the [standing queries](/docs/guides/websocket-api) (subscriptions) that push changes to your agent.
